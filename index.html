Suggested learning path

1) Build the transistor switch on a breadboard (BJT/MOSFET + resistor + LED, Arduino/ESP32 as driver) and observe Vin = 0 → OFF, Vin = 1 → ON. 2) Explore Module A here. 3) Build the NOT gate and compare with the X gate. 4) Meet superposition with H. 5) Implement the same function both ways. 6) Add noise and compare. 7) Take the pre/post assessment.

Build it physically

Quantum error correction: 3-qubit repetition code

    
Encode |0⟩ → |000⟩, correct a single bit flip by majority vote. The logical error rate is 3p² − 2p³, which beats the bare error rate p when p < 0.5. (Phase flips are handled the same way in the Hadamard basis.)

Protected error rate (simulated, 20000 trials)

      
Protected error rate (theory 3p² − 2p³)

    

    
Key comparison. Classical noise perturbs a continuous voltage, and the digital threshold removes it as long as it stays small. A qubit has no such built-in restoring step: errors act on amplitudes and phases, they cannot be copied-and-compared (no-cloning), and measuring destroys the state. Hence quantum error correction uses redundancy plus syndrome measurements instead of reading the data directly.
